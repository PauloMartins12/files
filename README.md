# Product & Operations Illustrations

An English Codex skill for visual explainers covering mining operations, AI products, and business intelligence. It includes Realist and Cartoon character references, reusable mining assets, diagram notation, and calibration examples.

## Install

1. Download this repository using **Code → Download ZIP**, then extract it.
2. Copy the `product-ops-illustrations` folder into your personal Codex skills directory (`~/.codex/skills/`), so `~/.codex/skills/product-ops-illustrations/SKILL.md` exists.
3. In Codex, ask for an illustration with `$product-ops-illustrations`. If the skill does not appear, restart Codex.

See [SKILL.md](product-ops-illustrations/SKILL.md) for its workflow and [NOTICE.md](product-ops-illustrations/NOTICE.md) for source credits and distribution context. The files are intended for internal use.
